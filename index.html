Troubleshooting

  • No device appears

    Try a different USB cable — most are charge-only, not data cables.

  • Flash fails or stops

    Try a different USB port. Unplug, wait 5 seconds, replug.

  • LED doesn't breathe

    Unplug and replug the ESP32. If still nothing, try re-flashing.

  • Mac: No serial port

    Search "CH340 driver Mac" and install the driver.

  • Windows: Driver issues

    Get CP210x drivers from Silicon Labs.

  • Still stuck

    Email wja326@lehigh.edu — we'll figure it out together.

What Is CRUMB?

The Idea

CRUMB teaches electronics through doing, not watching. Genesis Zero proves you can program a computer in 5 minutes. The barriers were never real — just badly designed gates.

The Pattern

Every computer follows the same pattern: Input → Process → Output. Your phone. Your car. This chip. Once you see it, you can build anything.

Philosophy

  • Truth as foundation — Every line of code documented. No gatekeeping.
  • Platform over product — Like Arduino. Like Linux. Yours to build on.
  • Cathedral thinking — Built to help people for decades, not months.

Open Source

GPL-3.0. Technology should adapt to humans, not the other way around. Fork it. Modify it. Build something better.
